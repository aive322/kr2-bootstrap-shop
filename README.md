# Горизонт — сайт турагентства на Bootstrap

Контрольная работа №2. Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

**Сайт:** https://aive322.github.io/kr2-bootstrap-shop/

## Описание

Многостраничный сайт вымышленного турагентства «Горизонт»: пляжный отдых, экскурсионные поездки и города Европы. На сайте есть главная страница, каталог из 19 туров с фильтрами, сортировкой и пагинацией, карточки туров с галереей, вкладками и отзывами, страница заявки, страница «О компании», страница отзывов с фильтрами, контакты и политика конфиденциальности. Все формы проверяются на стороне браузера.

## Фреймворк и способ подключения

Использован **Bootstrap 5.3.8**. Подключён **локально**, без CDN, поэтому сайт работает и без доступа к внешним сервисам:

- `vendor/bootstrap/css/bootstrap.min.css` — стили;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — скрипты (включает Popper), нужны для меню на мобильных, модального окна, вкладок, карусели, аккордеона и уведомлений;
- `vendor/bootstrap-icons/` — иконки Bootstrap Icons 1.11.3;
- `vendor/manrope/` — шрифт Manrope.

Собственные стили лежат в `css/custom.css` и подключены **после** Bootstrap, чтобы переопределять его значения (цвета, скругления, кнопки, отступы).

## Структура

```
index.html         главная страница
catalog.html       каталог туров: фильтры, сортировка, пагинация
product.html       карточка тура (Анталья)
product-2…19.html  карточки остальных туров
order.html         заявка на подбор тура
about.html         о компании: история, цифры, команда
reviews.html       все отзывы (открывается из карточек туров и с главной)
contacts.html      контакты и форма обратной связи
privacy.html       политика конфиденциальности
css/custom.css     собственные стили (после Bootstrap)
js/main.js         скрипты: маска телефона, проверка форм, фильтры каталога, окно заявки
vendor/            локальные файлы Bootstrap, Bootstrap Icons, шрифт
images/photos/     фотографии
```

## Использованные компоненты Bootstrap

- Сетка: `container`, `container-fluid`, `row`, `col-*`, `g-*`, `ratio`.
- Навигация: `navbar` (с кнопкой-бургером и `sticky-top`), `breadcrumb`, `nav-tabs`, `pagination`.
- Контент: `card`, `badge`, `btn`, `alert`, `table`, `list-group`, `progress`.
- Интерактивные компоненты: `modal`, `toast`, `carousel`, `accordion`, `collapse`.
- Формы: `form-control`, `form-select`, `form-range`, `form-check`, `input-group`, `btn-check`, валидация `needs-validation` с `invalid-feedback`.
- Утилиты: `d-flex`, `gap-*`, `py-*`, `shadow-sm`, `text-muted`, `d-none d-md-inline` и др.

## Собственные доработки

- Своя цветовая схема и шрифт, переопределение переменных Bootstrap в `css/custom.css`.
- Каталог на 19 туров: поиск, фильтры по направлению, цене, длительности и питанию, сортировка, постраничный вывод, состояние «ничего не найдено». Фильтры работают и из адресной строки (`catalog.html?dest=turkey`).
- Карточка тура: галерея-карусель из 5 фотографий, вкладки «О туре / Что входит / Экскурсии / Отзывы», программа, вопросы и ответы, блок бронирования, похожие туры.
- Отдельная страница отзывов: средняя оценка, распределение оценок, фильтры по направлению и оценке, постраничный вывод.
- Страница «О компании»: история, цифры со счётчиками, принципы, команда.
- Анимации: плавное появление блоков при прокрутке, счётчики, мягкие эффекты при наведении, тень шапки, кнопка «Наверх» в виде розы ветров (отключаются при настройке «уменьшить анимацию»).
- Форма заявки: маска телефона, проверка полей, подстановка выбранного тура и итоговая карточка.
- Окно быстрой заявки, уведомления после отправки форм.
- Адаптивная вёрстка для экранов от 360 px; уважается настройка «уменьшить анимацию».
- Bootstrap подключён локально, а не через CDN.
