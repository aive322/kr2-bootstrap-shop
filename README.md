# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект «Горизонт» — учебная версия сайта турагентства (каталог туров), разработанная с использованием Bootstrap 5.3.
Это отдельная реализация, не связанная с проектом контрольной работы №1.

## Практическая работа 9

Тема: «Bootstrap-сетка: container, row, col-* и базовая структура страницы».

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap CSS и JS Bundle через CDN;
- подключение `css/custom.css` после Bootstrap;
- шапка страницы и узкая полоса на `container-fluid`;
- Bootstrap-навигация (`navbar`);
- hero-блок на сетке (`col-12 col-lg-6`);
- блок преимуществ (`col-12 col-md-4`);
- сетка популярных туров (`col-12 col-md-6 col-lg-4`);
- подвал страницы.
