# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект «ТехноМаркет» — учебная версия интернет-магазина электроники, разработанная с использованием Bootstrap 5.3.
Это отдельная реализация той же предметной области, что и в контрольной работе №1 (`kr1-html-css-shop`).

## Практическая работа 9

Тема: «Страница на Bootstrap: сетка и адаптивность».

Выполнено:

- подключены Bootstrap CSS и JS Bundle через CDN;
- `css/custom.css` подключён после Bootstrap;
- шапка страницы и полоса `container-fluid` с акцией;
- hero-блок на сетке (`col-12 col-lg-6`);
- блок преимуществ (`col-12 col-md-4`);
- сетка популярных товаров (`col-12 col-md-6 col-lg-4`);
- подвал страницы.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация (`navbar`, `dropdown`) на все страницы;
- создана страница каталога `catalog.html`;
- создана страница товара `product.html`;
- создана страница заявки `order.html`;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `breadcrumb`, `table`;
- к товарам добавлены названия и изображения (`images/photos/*.jpg`, `card-img-top`; SVG-заглушки в `images/` как запасной вариант);
- добавлен файл `css/custom.css` для минимальных доработок;
- добавлен небольшой `js/main.js`: Bootstrap-валидация форм и сообщение об успешной отправке;
- проект подготовлен к сдаче контрольной работы №2.

## Используемые технологии

- HTML;
- Bootstrap 5.3;
- CSS;
- JavaScript (минимально);
- Git;
- GitHub.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html      — главная страница
├── catalog.html    — каталог товаров
├── product.html    — страница товара
├── order.html      — форма заявки
├── css/
│   └── custom.css  — дополнительные стили проекта
├── js/
│   └── main.js     — валидация форм и сообщения
├── images/         — SVG-заглушки; photos/ — фотографии товаров (JPG)
├── README.md       — описание проекта
└── .gitignore
```

## Как посмотреть проект

Открыть `index.html` в браузере. Для работы Bootstrap нужен доступ в интернет (подключение через CDN).
