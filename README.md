# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Сайт турагентства «Горизонт»: каталог туров, страницы туров, форма заявки на подбор и бронирование.
Интерфейс разработан на CSS-фреймворке Bootstrap 5.3.

## Практическая работа 9

Тема: «Bootstrap-сетка: container, row, col-* и базовая структура страницы».

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap CSS и JS Bundle через CDN;
- подключение `css/custom.css` после Bootstrap;
- верхняя полоса на `container-fluid`;
- адаптивная навигация (`navbar`);
- hero-блок с формой поиска тура;
- блок цифр и преимуществ (`col-12 col-sm-6 col-lg-3`);
- сетка популярных туров (`col-12 col-md-6 col-lg-4`);
- плитки направлений, этапы работы, отзывы;
- блок с формой обратного звонка и подвал.

## Используемые технологии

- HTML;
- Bootstrap 5.3 и Bootstrap Icons;
- CSS;
- Git;
- GitHub.
